.DMPSTER: Leapster 2 cart dumper

To install / run, copy SDMenu.bin to the internal storage / SD card and choose 
"game downloads" at the system main menu. If you have anything you care about on
your SD card / storage, you should back it up beforehand just in case something corrupts. 
Dumps are made to `/Leapster/[BIOS/CART]_0x[ROM_CHECKSUM]/bin`.
Attempting to reboot will just reload SD menu, so batteries will need to be removed after 
powering off to exit the homebrew.
