# .DMPSTER: Leapster 2 cart dumper

To install / run, copy SDMenu.bin to the internal storage / SD card (if it doesn't already
exist), and choose  "game downloads" (arcade icon, internal storage models) or "more
activities and games" (SD card icon, SD models) at the system main menu. If you have
anything you care about on your SD card / storage, you should back it up beforehand just
in case something corrupts. 

Dumps are made to `/Leapster/[BIOS/CART]_0x[ROM_CHECKSUM]/bin`.

Attempting to reboot will just reload the SD menu, so batteries will need to be removed
after powering off to exit the homebrew for now.

Note that cartridge ROMs cannot be booted as or converted to downloadable ROMs, as the
structure of downloadables and cartridge ROMs differ in such a way that we cannot convert
between the two as of now.
